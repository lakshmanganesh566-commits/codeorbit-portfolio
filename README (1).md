# Geddam Lakshman Ganesh — Portfolio Website

A personal portfolio website for showcasing profile information, skills, projects, and contact details. The About section uses a profile photo (`hero.png`) in place of the “LG” text.

## Project files

- `index.html` — Website page structure and content
- `style.css` — Styling and responsive layout
- `script.js` — JavaScript interactions
- `hero.png` — Profile photo used in the About section

## Run locally

1. Download and extract the portfolio ZIP file.
2. Keep `index.html`, `style.css`, `script.js`, and `hero.png` together in the same folder.
3. Open `index.html` in a web browser.

No build step or package installation is required for the basic static website.

## Customization

- Edit `index.html` to update text, links, and portfolio content.
- Edit `style.css` to change colors, spacing, and layout.
- Edit `script.js` to modify the page interactions.
- Replace `hero.png` with another image if desired, keeping the filename the same unless you also update its reference in the HTML.

## Deployment

This is a static website. You can publish the project folder using a static hosting service such as GitHub Pages, Netlify, or Vercel.
